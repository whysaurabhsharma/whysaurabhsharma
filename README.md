## Featured project

### [dot-content-machine](https://github.com/whysaurabhsharma/dot-content-machine)

An evidence-led content engine built in Claude Code for [Dot](https://getdot.ai), an AI data analyst. It turns a buyer's question into a finished piece, checks it harder than a reader would, and measures whether Dot gets chosen.

- **Seven stages**, from research to LinkedIn posts, each run by a Claude Code subagent or skill, with four decisions reserved for a person: the question, the outline, the title and publishing.
- **A 25 check quality gate** in Python that blocks export while any check fails.
- **Blind reviewers.** Reader, fact checker and lift tester subagents review a body-only copy and never see the writer's instructions.
- **Ground truth.** Every figure is recomputed from the raw data and marked against Dot's own answers, collected through an MCP connection.
